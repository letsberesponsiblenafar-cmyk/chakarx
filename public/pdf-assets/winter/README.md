# Winter artwork and shared-layout preview

`winter-cover.jpg` is the Winter PDF theme artwork, generated with the built-in image-generation tool. It is illustrative theme imagery, not a factual photograph of a named destination.

The selected 1024 × 1536 output was converted to a quality-95 JPEG without resizing. Text, logos, tables and page numbering are added separately by the PDF renderer as vector content; they are not baked into this image.

`winter-preview.jpg` is a rendered sample of the actual shared-layout PDF cover for the theme chooser. Winter retains the Original master’s frames, typography, tables and composition, with cool colours and winter imagery. Exports use `winter-cover.jpg` and draw the traveller's real dates and trip details as text, never the sample thumbnail. The preview is generated from the regression fixture in `tests/winter-pdf.cjs`.

## Final prompt

Use case: photorealistic-natural. Asset type: premium Kashmir travel itinerary PDF cover artwork. Create a refined photorealistic winter landscape inspired by Kashmir's Himalayan valleys: layers of snow-covered mountain ridges, dark evergreen forest and an untouched snow meadow, softly lit by clear winter morning light. Portrait composition, 2:3 aspect ratio, high resolution, crisp natural snow and pine textures. Calm glacier blue, deep blue-green shadows and luminous white, subtle warmth on distant peaks. A broad calm pale sky in the upper quarter provides negative space for a title added later as real text. Elegant editorial travel photography, not fantasy art. No text, no logos, no watermark, no people, no buildings, no borders. This is atmospheric theme artwork, not a map or a photograph claiming a specific destination.
