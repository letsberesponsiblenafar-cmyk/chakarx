# Deploy Chakar Experience to Vercel

Standard Next.js App Router project. Keep the repository root as the Vercel project root.

- Framework: Next.js
- Install: `npm install`
- Build: `npm run build`
- Node: 22.x

There are no Python functions and no Python runtime settings in this project.

After deployment, check `/`, `/hotels`, `/library`, `/sources`, `/planner/itinerary`, `/planner/hotels`, `/planner/costing`, `/planner/pdf`, `/api/health`, and `/api/hotels`.
