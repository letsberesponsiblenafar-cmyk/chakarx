# Deploy Chakar Experience to Vercel

Standard Next.js App Router project. Keep the repository root as the Vercel project root.

- Framework: Next.js
- Install: `npm install`
- Build: `npm run build`
- Node: 22.x

There are no Python functions and no Python runtime settings in this project.

Before deployment, create a Supabase project and run `supabase/schema.sql` in its SQL editor. Add these Vercel environment variables to Production and Preview:

- `SUPABASE_URL` — project URL.
- `SUPABASE_SERVICE_ROLE_KEY` — secret service-role key. Never prefix with `NEXT_PUBLIC_`.
- `CHAKAR_ADMIN_USER` — chosen admin username.
- `CHAKAR_ADMIN_PASSWORD_HASH` — generated by `node scripts/make-admin-hash.mjs`.
- `CHAKAR_SESSION_SECRET` — generated by the same script.

Redeploy after setting the variables. The app fails closed when admin credentials are absent. Visit `/login`, sign in, then upload the hotel master PDF at `/hotels`. The first import populates the new shared database. Check `/hotels`, an individual `/hotels/[id]` page, `/planner/hotels`, costing and a generated PDF. Signed-out requests to `/api/hotels` should return 401, and signed-out pages should redirect to `/login`.
